## 样式职责

样式通过 `src/styles/index.css` 统一引入。每个文件负责一种界面职责，同一组件的默认、交互和响应式样式放在一起，不使用按修改轮次排列的覆盖文件。

| 文件                  | 职责                                   |
| --------------------- | -------------------------------------- |
| `tokens.css`        | 颜色、字体、尺寸和动效变量             |
| `base.css`          | 基础排版、公共按钮、品牌图形、通用提示 |
| `layout.css`        | 三栏布局、顶栏、检查器与移动端面板     |
| `sidebar.css`       | 品牌、导航、会话历史与工作空间入口     |
| `conversation.css`  | 欢迎页、消息、正文排版、澄清与文本渐显 |
| `composer.css`      | 单行输入、自动长高、附件与发送／停止   |
| `tools.css`         | 工具状态、结果详情与来源展开           |
| `workflow.css`      | 流程画布、节点、缩放控件与全屏         |
| `artifacts.css`     | 产物文件树、生成提示与预览             |
| `accessibility.css` | 减少动态效果等系统偏好                 |

## 交互约定

- 助手正文没有头像和名称标题；时间在悬浮时显示。
- 输入区默认一行，上传和发送在左右两侧。换行或内容折行时向上长高，最多 160px，之后内部滚动。
- 新文字短暂错峰渐显，已有字符保留原来的动画时钟。最后一批字符完成淡入后去除动画包装，静态历史不重复播放。
- 手动向上滚动时退出底部跟随，返回底部后恢复跟随。
- 工具详情高度受限，较旧步骤默认收起；来源链接在工具区域内展开。
- 流程图和研究产物独立显示；产物仅列出实际文件，新生成文件播放一次蓝色扫光。

## 维护约定

组件、变量、文件和注释使用产品或技术职责命名。设计提示词、模型协作输出、临时分析与截图属于本地工作记录，不作为应用源码或产品文档的一部分。格式统一使用 `web/.prettierrc.json`，执行 `npm --prefix web run format`。
