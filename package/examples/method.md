# 小型方法比较实验

目标：在已有数据上比较基线与一个候选方法，判断改善是否稳定。执行前先核对用户提供的数据与代码位置；缺少真实资源时报告缺口。

约束：仅修改本实验工作目录；复用已有环境；不重新下载已有数据。以调用方给定的时间与计算预算为上限。

设计：固定数据划分和主指标，记录基线。按任务需要选择重复次数或种子，保留每次运行结果。候选方法失败也应记录；不为了得到改善而修改评价口径。

证据：保存实际命令、代码版本或差异、环境说明、数据标识、参数、原始日志和机器可读指标，图表附生成脚本。

完成条件：能够说明在已测试条件下结果支持什么、不支持什么，给出可定位的结果与局限。资源不足时交付部分成果和未完成项。
