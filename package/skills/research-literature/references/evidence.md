# 可定位的证据记录

每个来源记录稳定标识（优先 DOI，其次 URL）、题名、年份、访问日期及本地材料路径。条目可先写在任务目录的 sources.jsonl 中，再由主会话去重合并。

每个关键发现至少包含：主张；支持或反对；原文位置（页码/章节/表格）；简短摘录或忠实转述；研究条件与局限；这是原文结论还是本次推断。

示例（字段为项目约定，不是 Pi 内置协议）：

```json
{"id":"S001","url":"https://example.org/paper","title":"来源题名","accessed":"YYYY-MM-DD","localPath":"paper.txt"}
```

原始材料可保持原格式；无需为每篇论文建立独立 Agent 或数据库条目。检索结果不足时记录查询和筛选范围，避免对“没有找到”作超出检索范围的推断。
