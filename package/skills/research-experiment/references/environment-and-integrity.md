# 环境与研究诚信

## 可执行性

按任务需要检查：

1. 当前运行环境的 CPU、内存、磁盘及资源额度；所需软件、版本和数据路径。
2. 当前进程可访问的 GPU 或专用设备。设备被识别不等于框架兼容、显存充足或具有使用额度。
3. 方法实际使用的框架能否访问设备。缺少依赖时标记尚未安装，不能据此推断宿主机没有硬件。
4. 工作负载所需的模型规模、数据权限、计算时间和存储是否满足。

同包 research-task 的 `scripts/probe-environment.mjs` 提供共用的只读快速探测，不安装软件或查询云账户。对超时与无权限结果保留未知状态。容器中的硬件与内存可见性可能不同于实际配额，以部署层和任务级检查为准。按 [资源判断与共享运行](../../research-task/references/resources.md) 使用负载快照，不将可见资源全部占用。

## 资源不足

- 算力不足：如原目标允许，可做小规模真实验证，明确外推限制和未完成的大规模部分。
- 数据不可读或无授权：停止依赖该数据的结果生成，可继续不依赖它的文献或准备工作。
- 训练中断：保留实际日志、checkpoint 和进度，终值标记未测得。
- 任务要求仿真：按真实运行结果报告，并说明仿真设定和与现实观测的区别。

## 结果核对

`result.md` 按实际需要说明：

- 方法要求与本轮执行是否一致，调整及原因。
- 数据的来源、版本、访问情况和真实/合成/仿真性质。
- 实际检测和使用的设备、软件与运行条件。
- 可复查的命令、日志、退出码、原始结果和图表生成过程。
- 失败、异常、负结果、未完成工作及不能支持的结论。

## 项目边界

只在当前项目内生成代码、依赖、缓存和结果，外部输入按明确授权只读使用。只停止本任务启动且身份可确认的进程或远程作业，不根据进程名或 GPU 占用批量清理其他任务。

普通 Pi 中的 Bash、扩展和实验程序具有当前 OS 账户权限。Skill 规定工作范围，不能据此宣称已实现系统级或多用户隔离。缺少授权时向主会话交接具体条件，继续独立可做的工作。
