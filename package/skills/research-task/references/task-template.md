# task.md 示例（按需裁剪）

```markdown
# Research Task

## 研究目标
原始想法的忠实细化，包含研究对象和想解决的具体科学问题。

## 研究边界
- 必须：用户明确给定的约束；数据使用范围；评价或报告要求（如有）
- 可调整：工作假设与实现偏好（如有）

## 已有材料
- inputs/ 中与任务相关的上传文件、其他明确提供的材料路径或 URL；写明是否已实际验证可读

## 资源与可行性
- 当前已验证的硬件/权限与可能不足；未知就写未知

## 预期产出
- 可核查的分析、实验、图表、论文等；依本任务而定

## 尚待确认
- 仅列会影响后续研究的真正未知项；没有就省略
```

原始输入中的重要信息可附简短原文或链接。写完检查目标和硬性约束没有丢失。
